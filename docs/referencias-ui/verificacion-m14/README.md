# Evidencia M14: validación parcial

Las capturas son layouts con datos sintéticos, no una prueba física del ZTE.

- crear-*: obtenidas en una iteración estable de M14, con fuente ampliada y números visibles.
- m14-unirse-*: botón alcanzable mediante scroll en ventana sintética de 300dp; NO prueba IME real. Preceden al último ajuste del texto del campo.
- m14-tienda-*: PREVIAS al último ajuste de COMPRAR. Contienen el recorte que motivó la corrección; NO usarlas como aprobación final.
- Los nombres m12-* y otras capturas son reutilizados por el harness y pueden proceder de ejecuciones previas. No constituyen prueba nueva por sí solos.
- pruebas.txt contiene la última ejecución fallida por el proceso del AVD. limite-avd.txt registra ANR de arranque en varios procesos Android.

Falta repetir la suite instrumentada final y Auth Emulator con el entorno liberado de la presión de memoria.
